# AI-Enhanced Learning Architecture Section

A standalone recreation of the section shown in the screenshot. It is built as a small static site so it can be hosted independently without the rest of the original app.

## Files

- `index.html`
- `styles.css`
- `script.js`

## What is included

- Centered title and subtitle
- Three pill-style section tabs
- First-column accordion cards
- Responsive layout
- No framework dependency

## Hosting

Upload the three files to any static host and serve `index.html` as the entry point.

## Notes

The original repo contains this section in:

`artifacts/portfolio/src/components/sections/AIArchitecture.tsx`

The recreation keeps the same structure and content pattern, but removes the original React/Tailwind dependency so it can be hosted separately.
